# J.O.O.N.A.S. Joyride

Current release: 1.0.2

Ever feel like your J.O.O.N.A.S. keeps disappearing on you? Going on unauthorized breaks? Generally acting up?

Be the supervisor they deserve with J.O.O.N.A.S. Joyride. Hop on top of any J.O.O.N.A.S. and keep a closer eye on your hardworking little cleaning robot while it goes about its business.

The mod gives you two mounted positions:

- Surf mode keeps you standing up on top of the J.O.O.N.A.S.
- Tank mode lowers you into the robot so only your head sticks out.

## Controls

- `E` — Mount or dismount a nearby J.O.O.N.A.S.
- `F` — Switch between Surf mode and Tank mode while mounted.
- `C` — Cycle between first-person and third-person mounted camera views.

The mod remembers your last Surf/Tank choice and mounted camera preference between mounts and game sessions.

## Mod Manager settings

- `Diagnostics` — enables verbose troubleshooting logs. Disabled by default.

## Installation

1. Install BepInEx for Moon Sweepers.
2. Install MoonFramework.
3. Extract this archive into the Moon Sweepers game folder, keeping the `BepInEx` folder structure intact.

The plugin should end up at:

`BepInEx/plugins/JoonasJoyride/JoonasJoyride.dll`

## Optional Lunar Link installation

If Lunar Link is installed, the mod can be loaded and reloaded without restarting the game. Put the DLL at:

`BepInEx/hot/JoonasJoyride.dll`

Do not leave another active copy in `BepInEx/plugins`. Use Lunar Link's F9 window to enable or reload the hot copy.

## Notes

This mod does not change J.O.O.N.A.S. cleaning behavior or make the robot directly drivable. It simply lets you ride along in Surf or Tank mode.

The mod was tested on Moon Sweepers 1.0.5 with the current BepInEx and MoonFramework setup. Game updates may require compatibility testing.

And watch out for those capsule rockets!
